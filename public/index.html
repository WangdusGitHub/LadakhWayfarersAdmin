How to connect MongoDB Atlas (Cloud) or Local MongoDB:

  1. Open .env in this project directory.
  2. For MongoDB Atlas (Cloud), set: 
    MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/ladakh_wayfarers?retryWrites=true&w=majority
  3. For Local MongoDB, ensure mongod service is started: 
    MONGODB_URI=mongodb://127.0.0.1:27017/ladakh_wayfarers
  4. Save .env and restart with npm start or npm run dev.

How to activate Cloudinary Image Hosting (Free):

  1. Sign up for a free account at cloudinary.com.
  2. Copy your Cloud Name, API Key, and API Secret from your Cloudinary Dashboard.
  3. Add them to your .env file: 
    CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
  4. Restart the server. All photo uploads will instantly host on Cloudinary CDN!
